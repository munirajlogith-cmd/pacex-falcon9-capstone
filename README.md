# SpaceX Falcon 9 First-Stage Landing Prediction (Data Science Capstone)

## Run order
1. `1_data_collection_api.py` - SpaceX REST API
2. `2_data_collection_webscraping.py` - Wikipedia scraping
3. `3_data_wrangling.py` - cleaning and landing `Class` label
4. `4_eda_sql.py` - 10 SQL queries
5. `5_eda_visualization.py` - charts and one-hot features
6. `6_folium_map.py` - launch site map and proximity analysis
7. `7_spacex_dash_app.py` - Plotly Dash dashboard
8. `8_predictive_analysis.py` - four classifiers, grid search, confusion matrix

## Setup
`pip install pandas requests beautifulsoup4 matplotlib seaborn scikit-learn folium dash plotly`

Run in the IBM Skills Network Labs environment (or any machine with internet access)
so the course datasets and SpaceX API are reachable.
